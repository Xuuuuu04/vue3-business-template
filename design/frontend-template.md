# 前端模板设计

目标是让 AI 从业务包和计算图安排工作，用固定文件减少局部代理的任意发挥；同时让使用者得到一致、顺手的页面。模板自身承担重复的结构检查、字段来源、错误记录、并发处理和视觉约定。

## 三层理解

主代理先看业务线与开发包；进入包后看页面、状态、动作、接口和包间依赖；进入动作后看输入字段、命名步骤、产出与函数位置。代码与图使用同一份定义，文档只是该定义的生成结果。计划与已实现结构分开，真实测试与图的存在分开。

```
业务线 → 开发包 → 页面 → 页面状态 → 动作 → 命名步骤 → 声明接口
                 ↘ 公共组件          ↘ 字段来源与产出
开发包 → 已声明依赖的 public            ↘ 函数位置与运行记录
```

后端计算通常围绕一次请求和事务。前端还要处理输入、页面离开、浏览器返回、多个请求竞争、写入结果未知，以及 DOM 更新与屏幕绘制的区别。计算动作不会代替 Vue 渲染，也不会将所有点击与赋值变成流程节点。

## 结构怎样执行

生成器先建立固定文件与受保护的登记表。模块在应用入口明确登记。检查读取语法树、模块定义和登记表：多余文件、不存在文件、未注册包、跨包内部依赖、依赖环、重复路径、未经声明接口、字段来源错误与局部样式都会失败。相同结构检查在启动、打包和 CI 中执行。

运行器再次检查动作，使用独立数据和读写代理。步骤只能读取声明字段，写入类型检查后的新值；数组和嵌套对象同样只读。实际未产出声明字段和 return 返回结果均失败。结果必须有确定来源，可选步骤在图和运行记录中表达是否跳过。

拥有完整仓库写权限的代理仍然能够恶意修改所有检查。这套模板限制常见误写并留下差异，不宣称提供系统级权限隔离。主代理需要更硬的控制时，应限定子代理工作目录和可写文件。

## 运行质量

每个命名步骤记录执行时间、产出安全摘要、条件、错误、文件、行号和函数。请求记录真实 HTTP 状态、等待时间、请求编号与后台运行编号；演示服务不伪造后台编号。敏感字段与上传正文不记录原值，普通对象不展开保存。

浏览器记录最多 100 次动作与 200 个性能事件。容量溢出、浏览器不支持的事件和未返回后台编号都保持可见。记录只存当前页面内存，刷新会丢失；后台业务保存与前端开发记录有不同用途。

查询使用最新版本并取消旧请求；写入使用单次提交，不自动重试。已知失败和结果未知分开。成功响应无法解析也不能说明后台没保存。未知结果时先读取或由管理员确认，再决定后续操作。

运行器对命名业务步骤计时。第三方组件内部、浏览器绘制、网络系统和数据库内部不会自动变成前端函数节点；Vue 性能标记、浏览器工具与真实后台运行记录用于继续深入。没有测量的部分保持未知，不以估计数字补图。

## 视觉一致

采用 Vue3、Vue Router、Reka UI（无样式的可访问控件）、Tailwind 与 Zod，不再使用 Element Plus。控件的键盘、焦点和读屏行为来自 Reka UI；外观全部由模板自己的组件决定，所以能做到一致且细致。

界面系统分三层：主题输入（配色、圆角、疏密、侧栏风格）、语义色（背景、文字、边框、品牌色，由输入推出）、组件。业务页面只组合组件，不写颜色和样式。换配色只改输入，所有组件同时变；七套预设在浅色、深色、三种侧栏下的文字对比度由浏览器测试检查。

页面登记必须写 task，正文只使用一个主要工作区，整页最多一个主要操作。生成器与结构检查阻止卡片堆叠、正文前说明段落和多个主要按钮。标题下面不放说明小字，要让人知道的事实放进状态行。表格是重点：数字右对齐并带单位、固定列、勾选与批量操作条、行内展开、分组折叠、列设置、全屏、骨架读取与明确的空状态。复杂编辑和可分享详情使用独立页面，列表里的快速查看用抽屉，短决定用弹窗。表单失败保留输入，筛选和分页进入 URL，浏览器返回恢复滚动，未保存输入提醒覆盖路由切换与浏览器关闭。

默认正文与输入控件 16px，辅助文字不小于 12px。默认使用宽松间距，操作密集场景可切换紧凑模式。页面使用实色、细边框与稳定的文字层级；不追加纹理、光照和逐行出现的动画。

## 模板维护

干净产品初始化去掉样板业务与历史，保留模板来源和旧框架内容。更新比较旧模板、新模板、产品当前文件；冲突阻止整次写入，默认只预览。业务包和登记表不被覆盖，共用主题的产品修改也参与冲突判断。

CI 的作用是让误改检查、未执行测试和启动限制在远程再次被发现。模板不引入多余部署平台、插件、中间件或自建组件库。没有真实问题时不增加抽象。

官方依据：[Vue 性能与页面加载](https://vuejs.org/guide/best-practices/performance.html)、[Reka UI](https://reka-ui.com)。模板采用路由按需加载，开发模式保留 Vue 性能标记。

模块登记只包含说明、文件、页面与延迟加载入口。应用启动和结构图不导入各包的计算实现；进入页面后才下载相关步骤。生成图和开发检查读取完整定义，用同一份登记保持结构一致。
