# 界面系统

按单任务配方搭页面并用统一界面组件表达主次，对齐第一眼就懂与跟着已有印象走。

做页面前先确认三件事，写进页面登记的 `task` 后再动手：用户来这页做什么、第一眼先看什么、唯一的主要操作是什么。参考示例可操作 `/dev/examples`（代码在 `src/app/dev/examples/`），组件目录在 `/dev/design`，细节参数在 `src/shared/ui/README.md`。

## 选用页面结构

1. **按任务从配方选型**。总览、列表、表单、详情、会话和设置六种配方只在 [页面配方](../../../doc/ui-recipes.md) 维护，交付标准对照 [产品交付](../../../doc/delivery.md)。结构检查会拒绝多主区、多 `primary` 按钮、卡片堆叠、正文前说明段与局部写样式，按提示调结构。
2. **用实空间安排重点与层级**。主区占满剩余宽高，表单限制行宽（最大 760px），列表、图表和长文档在自身容器内滚动。页头标题下不加解释小字，动态状态放进状态行，帮助文字贴近控件。用字号、字重与颜色深浅区分主体与次要信息，不使用大面积留白或多余边框填屏。
3. **复用示例交互而不抄内存状态**。从 `/dev/examples` 借鉴页面排版、空态、错误态与未保存提醒，`useUnsaved` 接管离开确认；真实写入走动作执行器，草稿只在收到明确发送或保存成功回执后清空。

## 组件、尺寸与主题

1. **遵守语义变量与默认主题**。业务页只从 `@/shared/ui/public` 取组件，不写颜色、字号、`class` 和 `style`。模板默认石墨浅色、浅侧栏、纯色画布质感与宽松间距（行高 48px，切换紧凑后为 44px），品牌色和质感只在 `app.config.ts` 调整；正文字号 14px，辅助说明 13px，标注最小 12px，数字统一等宽。
2. **保障无障碍与键盘可达**。每个控件用独立 `Field` 自动关联名称、提示和错误；拖拽上传和色相条提供点击和方向键入口。复选框、开关等小图标保证足够点击面积，窄屏浮层两侧保留至少 12px 间距。长表与代码区只在自身区域滚动；表格行点击支持 Enter 和空格，行内按钮各自独立。
3. **按需扩展公共组件**：
   - 确有通用空白需求时放到 `base/`、`layout/` 或 `data/`，只使用语义色变量，导出到 `public.ts` 并在 `src/shared/ui/README.md` 与 `/dev/design` 补全说明和示例。
   - Reka 触发器不互相嵌套；新增配色需通过 `tests/browser/theme-contrast.spec.ts` 全组合对比度检查，改完检查差异再运行 `npm run framework -- --accept`。

## 画面比较与验收

1. **在真实条件下一并比较画面**。等字体加载完成（`fonts.ready`）、表格与图表数据就位且切页过渡结束后再检查；使用真实长度的中文名、金额与长标题，涵盖桌面、窄屏（320px / 390px）、深色模式及减少动态效果设置。
2. **对照八项视觉检查**：
   - 页面组织：第一眼能看清主任务，没有重复标题或无关卡片；
   - 字体层级：中英文与数字协调，主次字段区分明显；
   - 控件尺寸：行内操作不撑高数据行，紧凑和宽松模式实际行高准确；
   - 留白分隔：分组间距大于组内间距，标题与工具条衔接紧实；
   - 表面边界：工作区、表体、浮层互不混杂，不层层叠框与阴影；
   - 色彩对比：正文、辅助字与占位文字对比充足，状态色克制；
   - 完整操作：翻页、宽表横向滚动、键盘 Tab 焦点和返回滚动位置均可用；
   - 异常状态：空结果、加载骨架、查询失败重试和字段报错不破坏版式。
3. **如实汇报改造结果**。运行类型检查、结构检查和全部浏览器测试后，补充实际截屏画面核对；修改前后的视觉改善写清具体细节，把个人视觉判断和自动测试作为参考，最终设计验收以用户确认为准。
