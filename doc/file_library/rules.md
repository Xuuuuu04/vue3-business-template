# 文件管理规则

- R-01：按团队、offset 与 limit 读取。total 与文件信息来自后台；筛选只作用于当前页。确认样例：后台返回 1 条、total=16、offset=10，则页面显示这一条并保留总数 16。
- R-02：详情使用文件编号读取，支持直接进入与刷新。返回列表保留 URL 中的筛选与分页。
- R-03：选择一个非空文件，样板最大 10 MB；multipart 字段为 upload。只有后台返回有效 FileView 才表示上传成功，随后进入真实返回编号的详情。确认样例：3 字节文件返回 id=one，进入 one 的详情；空文件不发送请求。
- R-04：删除之前说明对象与结果，确认后执行。只有后台 204 表示完成，随后返回列表。删除不会由前端重试。
- R-05：下载采用后台实际返回的二进制内容，并回收临时地址。不把读取详情视为已经下载。
- R-06：提交中禁止重复；写入中断或响应格式错误表示结果未知。保留输入和可查询入口，不自动重发。确认样例：删除请求连接中断后再次点击，实际请求数量仍为 1。
- R-07：最新一次查询覆盖旧条件，旧响应即使更晚返回也不能覆盖新结果。页面退出取消在途读取。
- R-08：业务页使用统一组件、16px 起的字号与公共布局，不包含局部样式或左侧高亮条卡片。
- R-09：真实环境按 file_library.read / file_library.write 显示和执行动作；后台继续检查访问资格。演示环境明确无真实登录与权限判断。

这些是模板样板规则。真实产品的业务、数据保留策略、最大上传限制和权限由产品负责人明确后填写，不由局部代理补全。
