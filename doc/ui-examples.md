# 功能示例

开发时打开 `/dev/examples`，或者进入开发者工具 → 功能示例。侧栏直接切换五种完整任务，没有额外的示例首页。

| 页面 | 核心任务 | 可以体验 |
| --- | --- | --- |
| `/dev/examples/overview` | 看经营情况 | 重点趋势与关键数字、待处理事项、排名、构成、最近动态，统计范围切换 |
| `/dev/examples/customers` | 管理客户 | 搜索、状态筛选、排序、分页、查看详情、校验后新建客户 |
| `/dev/examples/campaign` | 编辑一场活动 | 分节表单、日期与人数校验、预览、保存、还原、未保存离开提醒 |
| `/dev/examples/approval` | 审批一笔采购 | 采购明细、整数分金额、必填理由退回、通过确认、审批记录与最终状态 |
| `/dev/examples/inbox` | 回复客户会话 | 搜索、未读、独立草稿、处理状态、桌面并排与手机逐页查看 |

所有人名、公司、申请与消息都是合成示例。操作只改变当前页面内存，刷新或离开后还原，不含真实客户写入、采购、付款或消息发送，仅供对照交互，不可当作后台接入样板。

示例代码位于 `src/app/dev/examples/`，只在开发工具开启时登记路由；生产默认关闭。显式开启生产开发工具仍需服务器限制访问。创建新产品会保留这些开发工具示例，默认业务登记不会增加客户、活动、采购或客服模块。

## 用于新页面

先确定用户要完成的一个任务，再参考相应例子的布局。业务开发仍使用 `new:module` 和 `new:page` 生成固定文件，页面通过动作状态调用已声明接口；不能直接复制示例的内存状态作为生产保存。

- 页面结构照[页面配方](ui-recipes.md)选，示例只用来看交互和真实数据下的效果。
- `useUnsaved` 接受页面自己的离开提醒；关闭浏览器时使用浏览器标准提醒。

颜色、间距、排版和窄屏规则仍由公共界面系统管理，不另写卡片样式或默认副标题。
