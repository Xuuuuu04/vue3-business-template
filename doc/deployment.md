# 真实后台接入与部署

开发时复制 .env.example，设置 VITE_API_MODE=real、API_PROXY_TARGET 和实际组织代码，然后运行 npm run dev:real。通过登录页面使用后端账号；前端请求同源 /api，由开发服务器代理到后台。不要把密钥或服务端配置放入 VITE_ 变量。

文件接口与 FastAPI 模板一致：列表、上传、info、download、DELETE。响应的 X-Request-ID 和 X-Run-ID 自动进入运行详情。后台仍检查组织、身份和操作权限；前端解码权限仅用于界面提示。

访问令牌只放内存，不写浏览器存储，也不自动刷新。刷新页面重新登录。退出当前页面仅清除访问凭据；如产品需要完整后台会话撤销或跨页面会话保持，应明确安全要求后增加统一会话能力。

生产执行 VITE_API_MODE=real npm run build，将 dist 作为静态资源。服务器将 /api 代理到后台，其他页面路径回到 index.html，才能支持详情直接访问。设置 HTTPS、合适的缓存及 CSP；HTML 不长期缓存，带内容指纹的资源可以长期缓存。

开发工具默认在生产关闭。VITE_SHOW_CONSOLE=true 会注册运行和组件查看页，若开放生产页面，服务器必须另外限制访问。源码映射默认不公开。没有服务端权限控制的前端路由不能保护秘密。

上线之前分别确认：实际账号权限、组织隔离、上传限制、真实存储、下载内容、删除结果、后台运行编号、直接访问和浏览器返回。浏览器样板测试不证明这些真实服务行为。模板仓库 CI 不执行生产部署。
