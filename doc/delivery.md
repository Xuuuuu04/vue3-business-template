# 产品交付

这份说明供接手模板的 AI 和开发者使用。先完成一项真实任务，再检查这项任务的页面、数据和失败处理。自动检查之后仍需人工完成业务和视觉验收。

## 从任务开始

1. 在业务规则里写清谁使用、处理哪个对象、成功结果、权限和异常样例。
2. 在页面登记的 `task` 写用户要完成的动作，例如“筛选客户并查看联系资料”，避免使用“智能总览”等无法验收的描述。
3. 用生成器创建页面，选择 `--layout list|form|detail|overview`。真实查询和保存未接入时保留明确的未实现状态。
4. 从 `/dev/examples` 选择最接近的完整任务，从 `/dev/design` 查看需要的控件。复用版式和交互，示例的内存保存不能作为产品数据处理。
5. 配置产品名、标识、联系方式和主题，连接真实后台，再检查以下完成条件。

## 页面与交互

各页面怎么搭只看[页面配方](ui-recipes.md)，这里只列交付前要确认的完成条件。

| 页面 | 完成条件 |
| --- | --- |
| 总览 | 每个面板回答一个问题、能点进完整页面；读取中和没数据用面板自己的状态 |
| 列表 | 筛选和分页进入地址；失败有重新读取入口；返回恢复位置 |
| 表单 | 错误贴近字段，失败保留输入，未保存离开有提醒 |
| 详情 | `SummaryBand` 加主体内容（明细、预览或记录），不是只有一张属性卡；直接进入、刷新、无权限和对象不存在都可用 |
| 会话 | 草稿按对象保存；明确发送成功后由页面清空 |

列表将查询动作的真实状态接入公共表格，不能把失败替换成空数组后显示“没有数据”。例如：

```vue
<DataTable
  :rows="rows" :columns="columns" row-key="id"
  :loading="state.status === 'loading'"
  :error="state.status === 'error' ? state.error : undefined"
  :total="state.data?.total ?? 0"
  retryable @retry="load"
/>
```

`load` 只执行已经声明的查询动作。页码在查询完成后校正，并通过 `v-model:page` 更新地址；读取中和失败时不依据临时零总数重置。行可点击时公共组件提供 Enter 和空格入口，行内按钮继续独立操作。

`PromptInput` 只发出 `send`，页面负责确认结果。明确失败或结果未知时保留草稿；成功后仅清除与本次发送相同的草稿，避免删除等待期间的新输入。发送中禁用重复提交，结果未知先查询。

表单将 `state.fieldErrors?.字段名` 传给 `Field error`；嵌套字段使用 `state.fieldErrors?.['lines.0.quantity']`。本地输入校验和后台 `fields` 都进入这个只读状态，敏感内容先清理，路径与条数受限。字段名由页面准确对应；提交期间停用字段和行重排，错误出现后保留草稿。未对应到字段的问题仍由整页提示说明。

本地校验遇到声明了 `secret` 的动作时，按安全规则处理：保留不回显输入值的自定义中文业务提示，其余错误收敛到已声明的顶层输入；没有敏感字段的动作保留业务自定义说明与准确嵌套路径。后台字段错误按请求路径显式对应。

## 外观

使用真实长度的名称、金额、日期和错误信息比较画面。先看一个完整任务是否清楚，再看字体、间距、边框和状态色。

- 页头只表达对象与主要操作。窄屏标题完整换行，操作另起一行；不靠截断标题隐藏当前任务。
- 表单分组标题占有限宽度，控件保持合适行宽。短表单无需扩大空框填屏。
- 主名称和次要时间、类型有明确层级。状态色表达事实；不添加装饰渐变、假数字、无关卡片或宣传小字。
- 手机的工具条、分页和弹层可操作，宽表只在表体滚动。深色、减少动态效果和键盘焦点一并检查。
- 页面不要自行写样式；先用公共组件，确有新用途再扩展公共系统。

最终画面比较遵循项目 `vue-ui` Skill，保留代表截图供人检查。

## 安全与资源限制

登录声明在提交时按需加载，全局搜索在首次打开时加载。权限提示与后端的 `public`、`signed_in`、全局及模块通配一致；每个非公开动作仍声明自身权限。退出或后续登录使较早的登录回复失效，旧动作停止后续请求，会话过期时离开受限页面。新产品初始化支持 `--name`，去掉样板身份与虚构联系方式，未配置密码帮助时不显示空链接。

性能记录区分绘制时点和事件耗时。绘制使用 `startTime`，不能把恒零的 `duration` 当成首次绘制速度；见 [Paint Timing](https://developer.mozilla.org/en-US/docs/Web/API/PerformancePaintTiming)。接口与未知资源不保存对象地址，静态资源去掉查询和凭据；页面切换只记录登记页面或声明路径。

| 机制 | 模板行为 | 产品需要决定的部分 |
| --- | --- | --- |
| 凭据与请求 | 令牌只存页面内存，只请求同源 `/api/`，拒绝重定向 | 登录接口、后台身份及资源权限 |
| 写入 | 单次提交，不自动重发；中断或响应不能确认时显示结果未知 | 如何查询已保存结果及业务幂等编号 |
| 响应 | 分块累计实际字节；JSON 默认 2 MiB、文件默认 32 MiB，错误正文 64 KiB | 分页、导出和文件接口可声明更小或更大的有限上限 |
| 请求期限 | 默认 15 秒；文件样例 120 秒，声明上限为 5 分钟 | 按网络与后台处理时间确定 `timeoutMs` |
| 前端加载 | 路由按需加载，构建超出启动代码或单块 gzip 预算时失败 | 真实数据量、图表规模、目标设备和产品资源预算 |
| 部署 | CSP、HTML 不缓存、带哈希资源长期缓存；API 不自动重试 | HTTPS、可信代理、真实账号和外部服务 |

`api.ts` 中可设置 `timeoutMs` 和 `maxResponseBytes`；响应声明最多 256 MiB。更大的文件应采用分批或服务端导出，不把大文件无限读入页面内存。上限是保护措施，不是设备容量或生产性能证明。

构建预算由产品根目录的 `build-budget.json` 配置：`initialCodeGzipBytes` 默认 204800 B（200 KiB），`assetGzipBytes` 默认 102400 B（100 KiB），字段只能填写正整数字节数。它是纯 JSON，缺失、非法或含未知字段时构建失败。模板更新保留产品自己的阈值。

`initialCodeGzipBytes` 分别核对每个 HTML 入口的启动静态 JS/CSS：HTML 中的脚本、代码预加载和样式，加上其静态导入及样式依赖；文件去重后按每个响应独立 gzip 的大小相加。动态导入不计入启动量，但每个 JS/CSS（包括懒加载块）仍受 `assetGzipBytes` 限制。引用缺失或不可计量的远程启动代码会使构建失败；与构建 `base` 同源同路径的 CDN 地址仍按本地产物计量。

此预算不包含 HTML、字体、图片、媒体和 API 数据，也不包含路由启动后动态加载的全部内容，不能称为完整首屏流量或设备性能验收。压缩值使用 Node.js `gzipSync` 的默认压缩参数，部署服务器的压缩策略不同可能得到不同传输大小。模板阈值用于发现体积回退，产品仍须按真实设备、网络和首屏任务测量。

构建输出会列出每个入口的实际值和限制，以及最大的 JS/CSS 文件。超限先检查新增依赖、静态导入和拆分是否合理；确需提高产品预算时记录业务理由和测量结果，不为使检查通过而自动提高阈值。

隐藏的手机导航使用浏览器 [`inert`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/inert)，关闭时不可聚焦，打开时背景不可交互。权限核对以后台检查为准。[OWASP 接口安全说明](https://cheatsheetseries.owasp.org/cheatsheets/REST_Security_Cheat_Sheet.html)

## 完成检查

运行 `npm run docs`、`npm run check`、`npm run test:browser` 和 `VITE_API_MODE=real npm run build`。公共框架变化先独立审查，再按 `vue-check` 更新摘要。不要降低检查要求来让它通过。

真实产品还要分别验证真实后台、部署和用户操作。模板自动检查通过，只证明所测范围；任何 AI 都能直接交付精良产品仍取决于业务规则、实际画面和人的验收。
