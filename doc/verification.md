# 检查证据

npm run check 执行结构、类型、框架错误场景、生成器和业务样例。实际结果写入本机 var/checks：整仓存 full.json，单包存 module-包名.json，互不覆盖，都包含源码指纹；project 分开显示两类结果，只在指纹一致时显示为当前结果，没有当前整仓记录时直接写明。

npm run test:browser 使用独立 HTTP 演示服务，检查上传、下载、删除、直接进入、刷新、浏览器返回、筛选、失败、未知结果、重复点击、窄屏、键盘和图查看。它证明前端对这些情形的处理，不代表真实后台验收。

真实 FastAPI 对接使用隔离数据和服务，结果应另外记录。部署与生产检查也单独说明。仓库里没有保存的“永久全部通过”结论；远程 CI 和本机代码修改后需要重新运行。
